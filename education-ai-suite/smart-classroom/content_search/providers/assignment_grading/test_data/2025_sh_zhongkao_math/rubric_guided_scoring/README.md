# 数学试卷Rubric说明

## 文件列表

- `Q19.json` - 第19题（8分）
- `Q20.json` - 第20题（8分）
- `Q21.json` - 第21题（10分）
- `Q22.json` - 第22题（10分）
- `Q23.json` - 第23题（10分）
- `Q24.json` - 第24题（12分）
- `Q25.json` - 第25题（20分，压轴题）

## 使用说明

这些是通用模板，需要根据实际试卷内容进行调整：

1. 打开对应的JSON文件
2. 修改 `question_text` 为实际题目内容
3. 调整 `scoring_points` 中的评分点，确保与实际题目要求匹配
4. 如果题目有特定的上下文（如函数图像、几何图形），在 `context` 字段添加
5. 可以添加 `standard_answers` 提供标准答案示例
6. 在 `few_shot_examples` 中添加更多实际评分案例

## 评分原则

数学题评分通常关注：
- 列式是否正确
- 计算过程是否完整
- 逻辑推理是否严密
- 最终答案是否准确

给分时既要看结果，也要看过程。
